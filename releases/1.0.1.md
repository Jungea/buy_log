## 변경 내용

- `관리 → 결제수단 관리`의 `미분류`를 제외한 결제수단에 `삭제` 버튼 추가
- 삭제 전 연결된 결제 건수를 확인창에 표시
- 앱 시작 시 삭제할 수 없는 기본 결제수단 `미분류`를 자동 생성
- 별도 결제수단을 만들지 않아도 첫 결제를 `미분류`로 등록 가능
- 연결된 결제를 옮길 결제수단 선택 UI 제공
- 이동 대상은 안전하게 `미분류`를 기본 선택하되 다른 카드·통장·현금 결제수단도 선택 가능
- 사용자가 `이동 후 삭제`를 확인한 경우에만 연결 결제의 수단을 변경하고 기존 결제수단 삭제
- 기존 결제, 태그 관계, 알림 원문과 결제 연결은 모두 보존
- 결제수단 변경과 삭제를 하나의 Room 트랜잭션으로 처리
- 신용카드와 체크카드만 선택적으로 카드 계산 기간·실적 관리 사용
- 통장·계좌이체·현금은 카드 설정 없이 일반 결제수단으로 등록 가능
- 계좌이체는 가능하면 `계좌이체`라는 공통 이름보다 실제 출금 통장 이름으로 등록하도록 안내
