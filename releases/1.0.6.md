# Release 1.0.6 — 앱별 알림 등록 상태 분리

## 상태

- 버전: `1.0.6`
- 상태: 구현 및 빌드 검증 완료
- 구현일: 2026-11-03

## 변경 내용

- `알림 설정 → 앱별 등록`을 `미허용`, `허용`, `차단` 탭으로 분리
- 각 탭에 해당 상태의 앱 수를 표시
- 앱별 등록 상세에서 세 상태를 바로 변경
- `차단` 앱은 기존 허용 목록에서 제거되고 자동 등록 대상에서 제외
- 기존 허용/미허용 설정은 그대로 유지하며 차단 상태만 별도 저장

## 데이터 변경

- Room 스키마 변경 없음
- 앱별 차단 목록은 기존 알림 설정의 로컬 설정에 저장

## 검증

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

- 단위 테스트 통과
- 디버그 APK 빌드 성공
- Android Lint 오류 0개

실제 기기에서 앱별 등록 탭 전환, 상태 변경, 차단 앱의 자동 등록 제외를 확인해야 한다.
