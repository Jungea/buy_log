## 목표

평소 결제가 자주 발생하는 요일과 시간대가 끝났는데 오늘 기록이 없다면, 결제 기록을 놓쳤는지 보수적으로 확인한다.

## 알림 조건

아래 조건을 모두 만족해야 알림을 표시한다.

- 사용자가 `패턴` 화면에서 `결제 누락 알림`을 직접 켠 상태
- 같은 요일의 완료된 관찰일이 6일 이상
- 해당 2시간 구간의 결제 발생률이 70% 이상
- 예상 시간대가 끝난 뒤 2시간 이내
- 오늘 해당 시간대에 저장된 결제가 없음
- 오늘 아직 누락 확인 알림을 표시하지 않음

따라서 누락 확인 알림은 하루 최대 한 번만 표시한다. 알림 기능의 기본값은 꺼짐이다.

## 알림 액션

### 결제 안 했어요

- 오늘 해당 시간대에 실제 결제가 없었다는 응답을 기기에 저장
- 같은 날짜의 추가 누락 알림 방지
- 응답 시 알림 닫기
- 향후 패턴 판단을 개선할 수 있도록 원본 응답 보존

### 직접 입력

- 앱을 열고 새 결제 입력창을 즉시 표시
- 사용자가 결제를 저장하거나 입력을 취소할 수 있음

## 구현 결과

- WorkManager를 이용한 1시간 간격 백그라운드 확인
- 기능을 켤 때 즉시 한 차례 확인
- Android 13 이상 알림 권한 요청
- 전용 `결제 누락 확인` 알림 채널
- 알림 켜기·끄기 설정 및 예약 작업 취소
- 기기 시간대를 적용한 누락 후보 계산
- 결제 존재 여부, 확인 시간 범위, 중복 알림 방지
- `결제 안 했어요` BroadcastReceiver 처리
- `직접 입력`에서 결제 등록창 바로 열기

WorkManager 작업은 Android의 배터리 최적화와 백그라운드 정책에 따라 정확히 매시 정각에 실행되지 않을 수 있다.

## 데이터 변경

- Room 데이터베이스 8 → 9 마이그레이션
- `missed_payment_checks`: 날짜, 예상 시간대, 확률, 알림·응답 상태 및 시각 저장
- 날짜별 고유 인덱스로 하루 중복 알림 방지
- 기존 결제, 태그, 카드 설정 및 자동 태그 규칙 유지

## 사용 방법

1. `패턴` 페이지를 연다.
2. `결제 누락 알림` 스위치를 켠다.
3. Android 13 이상에서는 알림 권한을 허용한다.
4. 충분한 결제 패턴이 쌓이면 예상 시간대가 지나간 뒤 누락 여부를 확인한다.
5. 알림에서 `결제 안 했어요` 또는 `직접 입력`을 선택한다.
