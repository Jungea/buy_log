## 화면 구성

Release 0.6에서 하단 메뉴를 `월간 | 결제 내역 | 카드`로 확장한다.

### 카드 페이지

- 카드사별 그룹과 카드별 항목 표시
- 조회할 카드 선택
- 카드별 현재 계산 기간 표시
- 해당 기간의 전체 결제금액
- 해당 기간의 실적 포함 금액
- 실적 목표, 현재 실적, 남은 금액, 진행률
- 해당 기간의 결제 이력
- 이전·다음 계산 기간 이동

## 카드별 기간 설정

- 계산 기준은 카드사가 아니라 개별 카드인 `PaymentMethod`에 저장한다.
- 같은 카드사의 카드라도 서로 다른 계산 기간과 실적 목표를 가질 수 있다.
- 화면에서는 같은 카드사에 속한 카드를 묶어서 보여줄 수 있다.
- 기본 기간은 매월 1일부터 말일까지로 한다.
- 사용자가 시작일과 종료일이 다른 기간을 설정할 수 있게 한다.
- 29일, 30일, 31일처럼 특정 월에 존재하지 않는 날짜는 해당 월의 마지막 날로 보정한다.

예시:

| 카드 | 계산 기간 |
|---|---|
| 신한카드 A | 매월 1일 ~ 말일 |
| 신한카드 B | 전월 15일 ~ 당월 14일 |
| 현대카드 | 전월 20일 ~ 당월 19일 |

## 집계 원칙

- Release 0.5의 소비 현황 페이지는 달력 월 또는 월급 주기를 기준으로 한다.
- 카드 페이지는 카드마다 설정된 고유 계산 기간을 기준으로 한다.
- 동일한 결제 원본을 사용하되 페이지에 따라 조회 기간만 다르게 적용한다.
- 태그의 소비 집계 제외 여부와 카드 실적 포함 여부는 독립적으로 관리한다.
- 소비 집계에서 제외된 결제도 카드 실적에는 포함될 수 있다.
- 사용자가 결제별 실적 포함·제외 여부를 수정할 수 있게 한다.

## Release 0.5와의 경계

- Release 0.5는 달력 월·월급 주기 기준의 소비 현황과 필터 가능한 전체 결제 내역을 제공한다.
- Release 0.6은 카드별 고유 기간, 카드 사용 이력 및 실적 계산을 제공한다.

## 구현 결과

- 하단 `카드` 페이지 추가
- 결제수단별 카드 여부, 카드사, 계산 시작일, 실적 목표 설정
- 계산 시작일부터 다음 달 시작일 전날까지를 카드 기간으로 적용
- 29~31일이 없는 달은 말일로 보정
- 카드 기간 이전·다음 이동
- 기간 전체 결제금액, 실적 포함 금액, 남은 금액, 진행률 표시
- 결제별 `카드 실적 포함` 스위치 제공
- 소비 집계 제외 태그와 카드 실적 포함 여부를 독립적으로 계산
- 카드 기간에 포함된 결제 이력 표시
