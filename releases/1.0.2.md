## 변경 내용

- 월급 주기 화면에 `주말이면 직전 평일로 조정` 설정 추가
- 설정 기본값은 켜짐이며 기기 내부에 저장
- 설정을 켜면 토요일 월급일은 전날 금요일, 일요일 월급일은 이틀 전 금요일로 보정
- 보정된 실제 월급일부터 다음 보정 월급일 전날까지를 하나의 소비 주기로 계산
- 월급일이 1일이고 주말 보정으로 전월 금요일로 이동하는 월 경계도 처리
- 공휴일은 휴일 데이터가 없으므로 자동 보정 대상에서 제외
- 회사 휴무 등으로 실제 입금일이 다른 경우 `대상 월`과 `실제 월급일`을 직접 지정
- 월별 직접 지정일은 기본 월급일과 주말 보정보다 우선 적용
- 저장한 지정일을 삭제하면 해당 달은 다시 기본 월급일·주말 보정 규칙 사용

## 데이터 변경

- Room 스키마 변경 없음: 데이터베이스 버전 9 유지
- 월급일 주말 보정 여부와 월별 실제 월급일은 기존 월급일과 함께 기기 내부 설정에 저장
