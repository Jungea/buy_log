# Release 1.0.3 — 알림 QA와 인식 앱 선택

## 상태

- 버전: `1.0.3`
- 상태: 구현 및 빌드 검증 완료
- 구현일: 2026-10-17

## 목표

실제 카드 결제 없이 알림 수집부터 결제 자동 등록까지 QA할 수 있게 한다. 알림 권한, 수집 이력, 앱별 자동 등록 설정을 분리하고 사용자가 허용한 앱의 신규 결제 알림만 자동 등록한다.

## 변경 내용

- `관리 → 알림 설정`을 권한 설정·앱 이력·앱별 등록의 세 페이지로 구성
- 권한 설정에서 QA용 `QA카드 승인` 시스템 알림 발행
- BuyLog의 일반 알림은 계속 제외하되 QA 채널 알림만 수집 허용
- 앱 이력에서 `결제 알림`과 `전체 알림` 필터 제공
- 전체 이력에서 미허용 앱을 바로 허용 가능
- 앱 선택 기본값은 없음으로 유지
- 선택하지 않은 앱 알림은 원문 목록에는 저장하지만 파싱과 자동 등록에서 제외
- 앱을 허용하기 전에 받은 알림은 다시 파싱하되 자동 등록하지 않고 `결제에 추가` 제공
- 앱을 허용한 이후 새로 도착한 결제 후보는 자동 등록
- 앱별 기본 결제수단 설정
- 알림 원문에 특정 키워드가 포함되면 지정한 결제수단으로 연결하는 규칙
- 긴 키워드를 우선 적용하고, 일치 규칙이 없으면 기본 결제수단 또는 `미분류` 사용
- 선택한 패키지 목록은 기기 내부 설정에 저장

## QA 흐름

1. 알림 접근 권한과 원문 알림 수집을 켠다.
2. `QA 결제 알림 보내기`를 눌러 BuyLog 알림을 목록에 수집한다.
3. 앱별 등록에서 BuyLog를 허용하고 기본 결제수단 또는 키워드 규칙을 설정한다.
4. 첫 알림은 앱 이력에서 `결제에 추가`로 등록할 수 있다.
5. QA 알림을 다시 보내 `BuyLog 테스트 상점`, `12,000원`의 자동 등록을 확인한다.

## 데이터 변경

- Room 스키마 변경 없음: 데이터베이스 버전 9 유지
- 인식 앱 패키지, 기본 결제수단, 키워드 연결 규칙은 `SharedPreferences`에 저장
- 기존 결제와 알림 원문은 변경하지 않음
