# Release 1.0.3 — 알림 QA와 인식 앱 선택

## 상태

- 버전: `1.0.3`
- 상태: 구현 완료, Android SDK가 있는 환경에서 빌드 검증 대기
- 구현일: 2026-10-17

## 목표

실제 카드 결제 없이 알림 수집부터 결제 자동 등록까지 QA할 수 있게 하고, 기기의 모든 알림이 결제 후보 판별로 넘어가지 않도록 사용자가 앱을 명시적으로 선택한다.

## 변경 내용

- `관리 → 알림 관리`에서 QA용 `QA카드 승인` 시스템 알림 발행
- BuyLog의 일반 알림은 계속 제외하되 QA 채널 알림만 수집 허용
- 수집된 알림의 앱·패키지 목록과 결제 후보 인식 스위치 표시
- 앱 선택 기본값은 없음으로 유지
- 선택하지 않은 앱 알림은 원문 목록에는 저장하지만 파싱과 자동 등록에서 제외
- 앱을 선택한 이후 새로 도착한 알림부터 결제 후보 판별
- 선택한 패키지 목록은 기기 내부 설정에 저장

## QA 흐름

1. 알림 접근 권한과 원문 알림 수집을 켠다.
2. `QA 결제 알림 보내기`를 눌러 BuyLog 알림을 목록에 수집한다.
3. 앱 목록에서 BuyLog를 결제 후보 인식 앱으로 선택한다.
4. QA 알림을 다시 보내 `QA카드`, `BuyLog 테스트 상점`, `12,000원` 후보 및 자동 등록을 확인한다.

## 데이터 변경

- Room 스키마 변경 없음: 데이터베이스 버전 9 유지
- 인식 앱 패키지 목록은 `SharedPreferences`에 저장
- 기존 결제와 알림 원문은 변경하지 않음

## 검증

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

- Gradle 9.5 배포본 준비 완료
- 현재 실행 환경에 Android SDK 경로가 없어 태스크 시작 전 중단됨
- Android SDK가 준비된 환경에서 위 명령을 다시 실행해야 함

실제 NotificationListenerService의 수신과 알림 표시 권한은 Android 기기에서 별도로 확인해야 한다.
