## 목표

최근 결제 기록을 이용해 요일과 시간대별 결제 발생 패턴을 로컬에서 분석한다. 데이터가 부족하거나 반복성이 낮으면 패턴을 억지로 표시하지 않는다.

## 분석 기준

- 최근 최대 8주 사용
- 아직 끝나지 않은 오늘은 분석에서 제외
- 기기의 명시적인 시간대를 기준으로 날짜와 시각 계산
- 요일별로 완료된 날짜가 최소 4일 쌓인 경우에만 분석
- 하루를 2시간 단위로 분할
- 같은 날짜의 같은 시간대에 결제가 여러 건 있어도 발생일은 1일로 계산
- 해당 요일 관찰일 중 50% 이상 발생한 시간대만 패턴으로 표시
- 요일별 확률이 높은 시간대 최대 3개 표시
- 머신러닝, AI, LLM 및 외부 서버를 사용하지 않음

예를 들어 최근 월요일 8일 중 6일에 12:00~14:00 결제가 있었다면 `75% (6/8일)`로 표시한다.

## 구현 결과

- 하단 메뉴에 `패턴` 페이지 추가
- 분석 기간과 요일별 관찰일 표시
- 시간대별 발생 확률과 실제 발생일/관찰일 표시
- 관찰 데이터 부족 상태 안내
- 분석 가능하지만 50% 이상 반복된 구간이 없는 요일 안내
- Release 0.9의 결제 누락 알림과 현재 통계 화면의 경계 명시

## 데이터 변경

- Room 스키마 변경 없음
- 기존 결제 기록을 읽어 실행 시점에 계산
- 분석 결과를 외부로 전송하거나 별도로 영구 저장하지 않음
