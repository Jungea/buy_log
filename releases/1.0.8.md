# Release 1.0.8 — 잉크 블루 테마와 앱 이력 개선

## 상태

- 버전: `1.0.8`
- 상태: 구현 및 빌드 검증 완료
- 구현일: 2026-11-03

## 변경 내용

- 흰색 배경과 잉크 블루 포인트 컬러를 적용
- 앱 이력과 앱별 등록의 상태 탭을 기존 `FilterChip` 스타일로 통일
- 앱별 등록 설명 문구를 탭 위에 표시하고 앱 이력과 텍스트 크기를 통일
- 앱 이력 진입 시 최신 알림 위치로 초기화
- 앱 이력 목록이 있으면 선택한 탭과 관계없이 맨 위로 이동 버튼 표시
