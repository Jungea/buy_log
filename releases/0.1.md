# Release 0.1 — 기본 결제 기록

## 상태

- 버전: `0.1.0`
- 상태: 구현 및 검증 완료
- 구현일: 2026-10-15

## 목표

사용자가 결제를 직접 기록하고 이번 달 소비 금액을 확인할 수 있는 실행 가능한 기본 Android 앱을 만든다.

## 구현 범위

- Compose 기반 단일 화면 앱
- 결제 수동 등록, 수정, 삭제
- 전체 결제 목록과 최근순 정렬
- 홈 상단에서 결제수단을 별도로 생성·관리
- 결제 등록·수정 시 현재 선택값이 표시되는 결제수단 선택 카드
- 이번 달 전체 결제금액 합계
- Room을 이용한 앱 종료 후 데이터 유지
- 입력 금액, 사용처, 일시, 결제수단 검증
- 삭제 전 사용자 확인

## 데이터 모델

### Payment

| 필드 | 타입 | 설명 |
|---|---|---|
| id | Long | 자동 생성 식별자 |
| amount | Long | 원 단위 결제 금액 |
| merchant | String | 사용처 |
| paidAt | Long | 결제 시각 epoch milliseconds |
| paymentMethodId | Long | 결제수단 외래 키 |
| memo | String | 선택 메모 |
| createdAt | Long | 생성 시각 |
| updatedAt | Long | 마지막 수정 시각 |

### PaymentMethod

| 필드 | 타입 | 설명 |
|---|---|---|
| id | Long | 자동 생성 식별자 |
| name | String | 중복되지 않는 결제수단 이름 |
| createdAt | Long | 생성 시각 |

## 집계 규칙

- Release 0.1에서는 모든 결제를 동일하게 합산
- 태그 기반 소비 집계 제외는 Release 0.5에서 적용
- 집계 기간: 기기 시간대 기준 현재 월의 시작 이상, 다음 달 시작 미만

## 결제수단 UI

- 새 결제수단 추가 기능은 결제 입력창에 포함하지 않는다.
- 홈 상단의 `결제수단 관리`에서 등록된 결제수단을 확인하고 새 결제수단을 추가한다.
- 결제 등록·수정 화면에는 현재 값이 굵게 표시되는 선택 카드를 제공한다.
- 선택 카드 우측에 `변경 ▼`를 표시하여 선택 가능한 영역임을 알린다.
- 등록된 결제수단이 없으면 홈 상단 관리 화면에서 먼저 추가하라는 안내를 표시한다.

## 데이터 이전

- Room 데이터베이스 버전은 2이다.
- 버전 1에 존재하던 `paymentType` 컬럼은 1→2 마이그레이션에서 제거한다.
- 기존 PERSONAL / TEST / ETC 구분은 제거하지만 결제 금액, 사용처, 일시, 결제수단, 메모 및 생성·수정 시각은 그대로 보존한다.
- 기존 결제는 모두 일반 결제로 동일하게 집계한다.

## 제외 범위

다음 기능은 의도적으로 포함하지 않았다.

- NotificationListenerService
- Push 및 SMS Notification 수집
- PaymentSourceEvent
- 결제 알림 파싱
- 자동 결제 등록
- 중복 결제 판정
- 카드 실적 관리
- 결제 태그 및 태그별 소비 집계 제외
- 자동 분류 규칙
- 결제 패턴 및 누락 알림

위 기능은 각 후속 릴리즈 요청 시 구현한다.
