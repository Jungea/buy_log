# Release 1.0.5 — 결제수단 관리 페이지

## 상태

- 버전: `1.0.5`
- 상태: 구현 및 빌드 검증 완료
- 구현일: 2026-11-03

## 변경 내용

- `관리 → 결제수단 관리`를 모달 대신 전체 페이지로 전환
- 상단 `뒤로`로 결제 기록 화면에 복귀
- 페이지 안에서 결제수단 추가·카드 설정·삭제와 연결 결제 이동을 계속 지원
- 관리 페이지에서는 하단 탭과 결제 추가 FAB를 숨겨 설정 작업에 집중
