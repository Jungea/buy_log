# Release 1.0.4 — 알림 리스너 자동 재연결

## 상태

- 버전: `1.0.4`
- 상태: 구현 및 빌드 검증 완료
- 구현일: 2026-10-20

## 목표

밤사이 Android의 알림 리스너 연결이 끊겨도 권한이 유지된 경우 다시 연결을 요청해 신규 알림 수집이 멈추는 시간을 줄인다.

## 설치 파일

- [BuyLog 1.0.4 디버그 APK 다운로드](https://github.com/Jungea/buy_log/raw/refs/heads/main/releases/1.0.4/buy-log-1.0.4-debug.apk)
- 파일 크기: 12,603,725 bytes
- SHA-256: `398641658FB472BA42276FB1BB51ABDCF9B441761F601992366F6626F3E5C652`

## 변경 내용

- `NotificationListenerService.onListenerDisconnected()` 구현
- 연결 해제 시 `requestRebind()`로 BuyLog 리스너 재연결 요청
- 원문 수집 스위치와 Android 알림 접근 권한은 기존처럼 사용자가 직접 제어
- 앱별 인식 설정과 기존 알림 이력 데이터는 변경하지 않음

## 데이터 변경

- Room 스키마 변경 없음: 데이터베이스 버전 9 유지

## 검증

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

- 단위 테스트 42개 통과
- 디버그 APK 빌드 성공
- Android Lint 오류 0개

실제 기기에서 알림 접근 권한과 원문 수집을 켠 뒤, 장시간 대기 후 QA 알림과 금융 앱 알림이 이력에 쌓이는지 확인해야 한다. Android 제조사별 배터리 제한이 활성화된 경우에는 BuyLog를 배터리 사용 `제한 없음`으로 설정해야 할 수 있다.
