## 목표

사용처 또는 메모에 지정한 문구가 포함된 결제를 저장할 때 선택한 태그를 자동으로 추가한다.

예시:

| 포함 문구 | 자동 태그 |
|---|---|
| `테스트몰` | 테스트 결제 |
| `PG_TEST` | 테스트 결제 |
| `출장` | 업무 |

## 구현 결과

- `태그 관리` 화면에서 자동 태그 규칙 추가·조회·삭제
- 규칙마다 포함 문구 하나와 적용할 태그 하나 지정
- 사용처와 메모를 대상으로 대소문자를 구분하지 않고 포함 여부 확인
- 한 결제에 여러 규칙이 일치하면 모든 해당 태그 적용
- 같은 태그를 지정한 여러 규칙이 동시에 일치해도 태그는 한 번만 적용
- 사용자가 직접 선택한 태그를 유지하면서 자동 태그를 추가
- 수동 결제 저장과 알림 기반 자동 결제 등록에 동일한 규칙 적용
- 태그 삭제 시 해당 태그를 사용하는 자동 규칙도 함께 삭제

자동 규칙은 규칙 생성 이후 새로 저장하거나 수정한 결제에 적용한다. 기존 결제 전체를 소급하여 변경하지 않는다.
