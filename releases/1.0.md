## 목표

Release 0.1~0.9의 데이터를 안전하게 보존하고 실사용 중 기기 변경이나 재설치에 대비할 수 있도록 로컬 백업·복원을 제공한다. 개인정보가 사용자 동의 없이 외부 백업으로 이동하지 않도록 기본 보안 설정도 정리한다.

## 구현 결과

### 로컬 백업

- 상단의 여러 관리 버튼을 하나의 `관리` 메뉴로 정리
- `관리 → 백업 및 복원 → 백업 파일 만들기`
- Android 파일 선택기에서 사용자가 직접 저장 위치 선택
- 확장자 `.buylog`의 버전형 백업 포맷 사용
- 최대 백업 파일 크기 50 MiB 제한

백업 대상:

- 결제수단과 카드 기간·실적 설정
- 결제와 결제별 실적 포함 여부
- 태그와 결제-태그 관계
- 특정 문구 자동 태그 규칙
- 수집한 알림 원문, 파싱 및 중복 처리 상태
- 결제 누락 확인 및 `결제 안 했어요` 응답

### 안전한 복원

- `관리 → 백업 및 복원 → 백업 파일 복원`
- 현재 데이터가 교체된다는 확인창 표시
- 파일 포맷 버전, 필드 형식, ID 중복 검사
- 결제-결제수단, 결제-태그, 자동 규칙-태그, 알림-결제 참조 검사
- 결제 금액, 카드 계산일, 실적 목표와 누락 확인 값 검증
- 파일 전체 검증이 끝난 후 하나의 Room 트랜잭션으로 교체
- 복원 도중 오류가 나면 기존 데이터 유지

### 개인정보 보호

- Android 자동 백업 비활성화
- 앱이 임의의 서버나 클라우드로 데이터를 전송하지 않음
- 사용자가 Android 파일 선택기에서 지정한 위치에만 백업 파일 작성
- 백업 파일에 금융 알림 원문이 포함될 수 있다는 경고 표시

알림 원문 수집 및 결제 누락 알림의 켜짐 상태는 시스템 권한과 연결되므로 백업·복원하지 않는다. 복원 후 사용자가 직접 다시 설정한다.

## 데이터 변경

- Room 스키마 변경 없음: 데이터베이스 버전 9 유지
- 백업 전용 DAO와 포맷 버전 1 코덱 추가
- 모든 기존 데이터의 ID와 관계를 보존하여 복원

## 범위 제한

- 취소·환불 자동 감지는 실제 카드사 알림 형식 검증이 더 필요하므로 추측해서 추가하지 않음
- 결제수단별 Push/SMS 선택은 실제 사용 중 필요성이 확인된 뒤 고급 설정으로 검토
- 백업 파일 자체 암호화는 포함하지 않으므로 사용자가 안전한 저장 위치를 선택해야 함
