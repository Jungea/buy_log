## 목표

달력 월 또는 사용자가 설정한 월급 주기를 기준으로 소비 현황과 결제 내역을 탐색하고, 태그를 이용해 실제 소비 집계에 포함할 항목과 제외할 항목을 유연하게 관리한다.

## 화면 구성

### 소비 현황 페이지

화면 상단에서 집계 기준을 전환한다.

```text
[ 달력 월 ] [ 월급 주기 ]
```

#### 달력 월 기준

- 선택한 월의 전체 결제금액
- 선택한 월의 실제 소비금액
- 선택한 월의 집계 제외 금액
- 가맹점별 사용금액
- 결제수단별 사용금액
- 이전 달·다음 달 이동

#### 월급 주기 기준

- 설정한 월급일부터 다음 월급일 전날까지의 전체 결제금액
- 같은 기간의 실제 소비금액과 집계 제외 금액
- 가맹점별·결제수단별 사용금액
- 이전·다음 월급 주기 이동
- 현재 조회 중인 시작일과 종료일 표시

예를 들어 월급일이 25일이면 `9월 25일~10월 24일`, `10월 25일~11월 24일`을 각각 한 소비 주기로 본다.

### 결제 내역·필터 페이지

- 달력 월 또는 월급 주기 선택
- 선택한 소비 기간에 포함된 결제 목록
- 결제수단 필터
- 태그 필터
- 가맹점 검색
- 집계 포함·제외 필터
- 기간 직접 지정
- 필터 결과 합계

Release 0.5 시점의 기본 하단 메뉴는 `월간 | 결제 내역`으로 구성한다. Release 0.6에서 `카드` 페이지를 추가한다.

## 구현 범위

- 태그 생성, 수정, 삭제
- 결제에 여러 태그 지정
- 태그 필터
- 태그별 `소비 집계 제외` 설정
- 제외 태그가 지정된 결제금액을 실제 소비에서 제외
- 제외된 결제도 원본 기록과 전체 결제금액에는 유지
- 확인이 필요한 중복 후보 표시
- 월급일 설정
- 집계 기준 `달력 월 / 월급 주기` 전환

## 집계 원칙

- 전체 결제금액은 확정된 모든 결제를 포함한다.
- 실제 소비금액은 `소비 집계 제외` 태그가 없는 결제만 포함한다.
- 한 결제에 제외 태그가 하나라도 있으면 실제 소비금액에서 한 번만 제외한다.
- 태그 설정을 바꾸면 월간 집계에 즉시 반영한다.
- 소비 집계 제외 여부와 카드 실적 포함 여부는 서로 독립적으로 관리한다.

## 월급 주기 규칙

- 월급일은 1~31일 중 하나로 설정한다.
- 월급일 당일을 새 소비 주기의 시작일로 포함한다.
- 주기의 종료일은 다음 월급일의 전날이다.
- 설정한 날짜가 특정 월에 없으면 그달의 마지막 날로 보정한다.
- 초기 버전에서는 주말·공휴일에 따른 실제 입금일 변동을 자동 추정하지 않고 설정한 날짜를 기준으로 한다.
- 월급 주기는 개인 소비 집계를 위한 기준이며 카드별 계산 기간과 별도로 관리한다.

## 예시

| 결제 | 태그 | 전체 결제 | 실제 소비 |
|---|---|---:|---:|
| 테스트몰 100원 | 테스트 · 집계 제외 | 포함 | 제외 |
| 스타벅스 4,500원 | 식비 | 포함 | 포함 |
| 업무 교통비 20,000원 | 업무 · 집계 제외 | 포함 | 제외 |
