# Release 0.2 — 알림 원문 수집

## 상태

- 버전: `0.2.0`
- 상태: 구현 및 빌드 검증 완료
- 구현일: 2026-10-15

## 목표

실제 사용하는 금융 앱 Push와 문자 앱의 SMS Notification 형식을 로컬에서 확인할 수 있도록 한다. 이 릴리즈에서는 결제를 자동 생성하지 않는다.

## 설치 파일

- [BuyLog 0.2.0 디버그 APK](0.2/buy-log-0.2.0-debug.apk)
- 파일 크기: 12,010,252 bytes
- SHA-256: `E78E6BD3A9C7D445E837CCC8C30D9F8835F07DCD791553A29D53FA6B3E0DDA48`

휴대폰으로 APK를 전달해 설치하면 USB 또는 무선 디버깅 연결 없이 실제 기기에서 알림 수집을 테스트할 수 있다. 설치 과정에서 Android가 알 수 없는 앱 설치 허용을 요청할 수 있다.

## 구현 범위

- `NotificationListenerService` 등록
- Android 알림 접근 권한 설정 화면 진입
- 사용자 명시적 `원문 알림 수집` 시작·중지 제어
- 수집 기본값 꺼짐
- 알림 패키지명, 앱 이름, 제목, 내용, 원문, 수신 시각 로컬 저장
- 최근 200건을 보여주는 알림 로그
- 알려진 문자 앱 패키지를 `SMS_NOTIFICATION`으로 분류
- 나머지 앱 알림을 `APP_NOTIFICATION`으로 분류

## 사용 흐름

1. 홈 상단의 `알림 로그`를 연다.
2. `권한 설정`에서 결제 기록 앱의 알림 접근 권한을 켠다.
3. `원문 알림 수집`을 켠다.
4. 금융 앱 또는 문자 앱 알림을 받은 뒤 로그에서 원문 형식을 확인한다.
5. 형식 확인이 끝나면 수집을 끈다.

## 데이터 모델

### NotificationEvent

| 필드 | 설명 |
|---|---|
| sourceType | `APP_NOTIFICATION` 또는 `SMS_NOTIFICATION` |
| packageName | 알림을 보낸 Android 패키지명 |
| appName | 설치된 앱 이름 |
| title | 알림 제목 |
| content | 알림 내용 |
| rawText | 제목·내용을 조합한 원문 |
| receivedAt | Android 알림 게시 시각 |
| createdAt | 로컬 저장 시각 |

Room 데이터베이스는 버전 2에서 3으로 올라가며, 기존 결제와 결제수단 데이터는 변경하지 않는다.

## 개인정보 원칙

- 알림 원문 수집은 기본적으로 꺼져 있다.
- 사용자가 수집을 켠 동안 받은 알림만 기기에 저장한다.
- 데이터는 외부 서버로 전송하지 않는다.
- 디버그 로그는 형식 확인이 끝나면 수집을 끄는 용도다.
- 이 단계에서는 금융 앱 여부를 완전히 식별하지 않으므로, 수집을 켠 동안 받은 내용 있는 알림이 로컬 로그에 저장될 수 있다. 필요한 형식을 확인한 뒤 수집을 끈다.

## 제외 범위

- 알림 내용에서 금액·가맹점·결제시각 파싱
- PaymentCandidate 생성
- Payment 자동 생성
- Push와 SMS의 중복 판정 및 병합
- Android SMS 데이터 직접 접근
- 결제수단별 수집 대상 설정

위 기능은 후속 릴리즈에서 실제 기기 로그를 바탕으로 구현한다.

## 검증

```powershell

```
